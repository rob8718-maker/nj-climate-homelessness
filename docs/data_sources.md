# Data Sources

## HUD Point-in-Time Count
- **URL:** https://www.hudexchange.info/resource/3031/pit-and-hic-data-since-2007/
- **Coverage:** 2007–2024, annual, CoC-level
- **NJ CoCs:** NJ-500 (Atlantic City), NJ-501 (Bergen), NJ-502 (Burlington), NJ-503 (Camden), NJ-504 (Cape May), NJ-505 (Cumberland/Salem/Gloucester), NJ-506 (Essex), NJ-507 (Hudson), NJ-508 (Hunterdon/Somerset/Warren), NJ-509 (Mercer), NJ-510 (Middlesex), NJ-511 (Monmouth), NJ-512 (Morris), NJ-513 (Ocean), NJ-514 (Passaic), NJ-515 (Sussex), NJ-516 (Union)
- **Notes:** Download the Excel workbook; tab structure changes slightly across years

## NASA SEDAC
- **URL:** https://sedac.ciesin.columbia.edu/
- **Datasets of interest:** Climate Hazards Group InfraRed Precipitation (CHIRPS), Gridded Population
- **Access:** Requires free Earthdata account

## NOAA NCEI
- **URL:** https://www.ncei.noaa.gov/
- **Datasets:** Monthly temperature normals, extreme precipitation events, storm data
- **Formats:** CSV (summaries), NetCDF (.nc) for gridded data

## NJ Geospatial
- **County boundaries:** https://njogis-newjersey.opendata.arcgis.com/
- **CoC boundary shapefiles:** HUD EGIS (https://hudgis-hud.opendata.arcgis.com/)
